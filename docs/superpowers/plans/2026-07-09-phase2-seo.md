### Task 2: SEO.jsx — /faq ページの FAQPage 構造化データを正しく分離出力する

**Files:**
- Modify: `src/components/SEO.jsx`
- Modify: `src/App.jsx` （3箇所: PAGE_META・/faq customJsonLd の削除・SEO呼び出し）

**背景:** App.jsx の `/faq` 分岐（`} else if (location.pathname === '/faq') {`）にはすでにFAQ JSON-LDが
ハードコードされているが、`customJsonLd` を spread でマージする現行実装では WebPage スキーマと FAQPage スキーマが
一つのオブジェクトに混在する。Task 1 で切り出した `faqData.js` を使い、FAQPage を別の `<script>` タグとして
正しく出力する形に直す。

**Interfaces:**
- Consumes: Task 1 完了（`src/faqData.js` の `FAQ_CATEGORIES` が使用可能）
- Produces:
  - `/faq` ページで `<script type="application/ld+json">` が2つ出力される（WebPage + FAQPage を別スクリプトに分離）
  - App.jsx の `/faq` ハードコードFAQ JSON-LDブロックが削除される
  - faqData.js から自動生成されるため、FAQ_CATEGORIESに追加するだけで反映される

- [ ] **Step 1: SEO.jsx を更新する（import追加・faqSchema prop追加・FAQPage JSON-LD出力追加）**

  `src/components/SEO.jsx` を以下の通り変更する：

  先頭importに追加：
  ```js
  import { FAQ_CATEGORIES } from '../faqData'
  ```

  コンポーネント関数シグネチャを変更（`faqSchema` を追加）：
  ```js
  export default function SEO({ title, description, ogType = 'website', customJsonLd, keywords, faqSchema }) {
  ```

  `const breadcrumbs = ...` の後（`return (` の直前）に追加：
  ```js
  const faqJsonLd = faqSchema
    ? {
        '@context': 'https://schema.org',
        '@type': 'FAQPage',
        mainEntity: FAQ_CATEGORIES.flatMap(cat =>
          cat.items.map(item => ({
            '@type': 'Question',
            name: item.q,
            acceptedAnswer: { '@type': 'Answer', text: item.a },
          }))
        ),
      }
    : null
  ```

  `<Helmet>` 内の `</Helmet>` 直前（breadcrumbJsonLd の `<script>` の後）に追加：
  ```jsx
  {faqJsonLd && (
    <script type="application/ld+json">{JSON.stringify(faqJsonLd)}</script>
  )}
  ```

- [ ] **Step 2: App.jsx の `/faq` ハードコードFAQ JSON-LDブロックを削除する**

  App.jsx のカスタム JSON-LD 生成部分（`let customJsonLd = {}` 以降）の中にある
  `} else if (location.pathname === '/faq') {` で始まるブロック全体（`customJsonLd = { '@type': 'FAQPage', ...` から次の `}` まで）を削除する。

  削除後、`/faq` パスに対しては `customJsonLd` は `{}` のまま（デフォルト）になる。

- [ ] **Step 3: App.jsx の PAGE_META '/faq' に `faqSchema: true` を追加する**

  Task 3（PAGE_META最適化）と合わせて実施予定だが、先に追加しておく：
  ```js

    ogType: 'website',

  ```

- [ ] **Step 4: App.jsx の `<SEO>` 呼び出しに `faqSchema` を渡す**

  App.jsx の return 内の `<SEO ... />` を以下に変更：
  ```jsx
  <SEO
    title={meta.title}
    description={meta.description}
    ogType={meta.ogType}
    customJsonLd={customJsonLd}
    keywords={keywords}
    faqSchema={meta.faqSchema}
  />
  ```

  4. `/` や `/voices` では FAQPage JSON-LD が出力されていないこと
