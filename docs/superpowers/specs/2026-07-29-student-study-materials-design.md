# 在学生向け学習教材セクション 設計

- 日付: 2026-07-29
- ステータス: 承認済み（ユーザー確認済み）

## 背景・目的

`docs/応用栄養学_演習問題_20問.html` として、管理栄養士国家試験「応用栄養学」の自己採点式演習問題（5肢択一・20問）が用意された。これをサイト上で公開し、かつ今後も同形式の演習問題（他科目）を追加していけるセクションを新設する。

## 想定読者・位置づけ

- **主対象**: 食物栄養学科の在学生（自習用の実用ツール）
- 受験生向けPRではない。そのため既存の `kokushi-report`（国試対策の取り組みをPRする記事）とは役割が異なり、`/support`（国試対策サポート体制ページ）の延長にある「実際に使えるツール」という位置づけ。
- サイトはログイン機構を持たない完全公開の静的サイトのため、本教材も一般公開ページとして実装する（アクセス制限なし）。

## 今後のコンテンツ計画

- 当面は本演習問題のような**自己採点式クイズHTML**が中心。
- 他科目（応用栄養学以外）のクイズも今後追加予定。
- PDF/スライド資料などの他形式は現時点では未定。今回の設計では扱わず、必要になった時点で別途検討する（YAGNI）。

## URL・ページ構成

新セクション「学習教材」を `/study` に作成する。既存の Labs/Columns と同様、ハブページ＋個別詳細ページの構成。

- **ハブページ**: `/study`
  - `src/pages/study.astro` → `src/components/Study.astro`
  - 科目ごとのクイズをカード一覧表示（カードグリッド）。現時点でクイズは1件のみだが、複数科目を見越した一覧UIとする。
  - Columns/Labsのようなカテゴリフィルタ機能は、クイズが1〜数件のうちは不要。将来的にクイズ数が増えて必要になったら追加検討。
- **個別クイズページ**: `/study-applied-nutrition`
  - `src/pages/study-applied-nutrition.astro`（既存ページは全て `src/pages/` 直下にフラットなハイフン区切りファイル名で置かれており、サブディレクトリを持たない規則。`lab-kamiyama-report.astro` 等の命名パターンを踏襲し、ネストしたURL（`/study/xxx`）にはしない）
  - 今回の応用栄養学20問クイズを表示。

## 再利用可能なクイズコンポーネント

今後も同形式のクイズが増える前提のため、クイズ表示ロジック（選択→採点→解答解説表示、スコア集計、スコアバーのsticky表示、リセット機能）を共通コンポーネント化する。元HTMLの `<script>` 内ロジック（約200行）をベースに移植する。

- `src/components/quiz/QuizEngine.astro`
  - Props: `title`（クイズ名）、`sections`（質問データ配列。各質問は `sec`（見出し）, `q`（問題文）, `opts`（選択肢配列）, `ans`（正解番号）, `exp`（各選択肢の解説配列）, 任意で `note`（補足）を持つ）
  - 出題・採点・解説表示・スコア集計・リセットは vanilla `<script>` 内で実装（サイト既存パターン：Labs/FAQ/Columnsと同様、Reactは使わない）
  - TypeScript element genericsで `querySelectorAll<HTMLElement>` 等を使い `astro check` を通す
- `src/data/quizzes/applied-nutrition.js`
  - 元HTMLの `QUESTIONS` 配列をそのままデータとして切り出す（20問、4セクション構成は維持）
- 今後別科目のクイズを追加する際は、新しいデータファイル1つ＋薄いページファイル1つ（`QuizEngine` を呼び出すだけ）で追加できる形にする。

## デザイン

サイトのデザイントークン（`src/index.css` の `--terracotta`/`--forest`/`--cream`/`--charcoal`/`--stone` 等のCSSカスタムプロパティ、`--font-serif`/`--font-sans`）に合わせて再構築する。元HTMLの青系配色（`--primary:#1e3a8a` 等）は使わず、UIパターン（選択肢ボタン、正誤ハイライト、スコアバー、解説カード）は踏襲しつつ配色・フォントをサイト仕様に統一する。新規CSSファイルは作らず `src/index.css` に追記する（既存方針を踏襲）。

## ナビゲーション導線

在学生向けの実用ツールであり、受験生向け導線が主目的のメインヘッダー（`Header.astro`）には追加しない。

- **Footer.astro**: `LINK_COLS`（ナビリスト）に「学習教材」→ `/study` を追加。`/support`（国試対策）の近くに配置。
- **`/support`（`NationalExamSupport.astro`）**: 「演習問題を解いてみる」といったCTAリンクを追加し `/study` へ誘導する。

## メタ情報・SEO

- `src/data/pageMeta.js` の `PAGE_META` に `/study` と `/study-applied-nutrition` のエントリを追加する（`BaseLayout.astro` は未登録パスをビルドエラーにするため必須）。
- News（`src/newsData.js` の `STATIC_NEWS`）や Columns への掲載は行わない。既存の `type` 値（`info`/`news`/`event`/`report`/`voice`/`column`/`sensei`）に「学習教材」に適した種別がなく、お知らせ的コンテンツではなく常設ツールであるため対象外とする。

## スコープ外（今回やらないこと）

- ログイン・アクセス制限の実装（サイトの静的公開方針を踏襲し不要）
- カテゴリフィルタUI（クイズ件数が少ないうちは不要）
- PDF/スライド資料の掲載機構（今回はクイズHTML形式のみを対象）
- ヘッダーメインナビへの追加

## テスト方針

- `npx astro check` で型エラー0件を確認
- `npx astro dev` でクイズの選択→正誤判定→解説表示→スコア集計→リセットの一連の動作をブラウザで確認
- レスポンシブ確認（元HTMLに `@media (max-width:600px)` があるため、モバイル幅でも確認）
