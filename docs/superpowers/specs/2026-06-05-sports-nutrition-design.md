# `/sports-nutrition` ページ 設計仕様書

**作成日**: 2026-06-05  
**URL**: `/sports-nutrition`  
**コンポーネント**: `src/components/SportNutritionPage.jsx`  
**目的**: 食物栄養学科でもスポーツ栄養が学べることを受験生に訴求し、食物栄養学科への出願意欲を高める

---

## 背景・課題

「管理栄養士養成課程（食物栄養学科）はスポーツ系が学べない」という受験生の先入観が存在する。
実際には以下の要素によってスポーツ栄養学を体系的に学べるが、広報が不十分。

- **他学科開放制度**: 健康栄養学科のスポーツ栄養学・運動生理学を自由選択科目として履修可能
- **教員陣**: 日本スポーツ栄養学会理事（村田浩子教授）・公認スポーツ栄養士（徳野裕子准教授）が指導
- **資格の優位性**: 公認スポーツ栄養士の受験要件は「管理栄養士免許」が必須 → 食物栄養学科が最短ルート
- **実践環境**: カレッジスポーツセンター（CSC）を通じた実践プロジェクトへの参加機会

---

## ターゲット

- スポーツ栄養に興味があり大学の学科選択を検討している高校生
- 進路指導教員
- 既に食物栄養学科に関心があるが「スポーツ系も学びたい」と迷っている受験生

## 技術要件

### 登録が必要な箇所（CLAUDE.md「4ヶ所ルール」）

1. **`App.jsx` `PAGE_META`**: `'/sports-nutrition': { title: 'スポーツ栄養 | 十文字学園女子大学 食物栄養学科', desc: '...', ogType: 'website' }`
2. **`App.jsx` `SUB_PATHS`**: `'/sports-nutrition'` を追加
3. **`App.jsx` `<Routes>`**: `<Route path="/sports-nutrition" element={<SportNutritionPage />} />`
4. **`Header.jsx`・`Footer.jsx`**: 適切なカテゴリに追加（「特集・コンテンツ」等）

### スタイル

- `src/index.css` のみに追記（新規CSSファイル不可）
- 既存の `.lab-page`, `.lab-section`, `.lab-story-feature`, `.lab-theme-card` 等を最大限活用
