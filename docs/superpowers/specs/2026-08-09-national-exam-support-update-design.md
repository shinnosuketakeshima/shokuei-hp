# 国家試験対策ページ（/support）更新設計

日付: 2026-08-09
対象: `src/components/NationalExamSupport.astro`（`/support` フルページ + ホーム要約）と、同じ数値・施策を参照している周辺ファイル

## 背景・目的

`docs/国家試験対策.pptx`（教員 飯村九林、作成2026-03-16／最終更新2026-07-31）に、食物栄養学科が対外的に使う国家試験対策の新しい説明フレームが確定した。このpptxの内容をベースに、現在の`/support`ページ（およびホームのサマリー、関連する数値を引用している他ページ）を最新化する。

## 事実確認：合格率の数値について

pptxスライド2は「国家試験合格率（新卒全国平均）25年 83.9% / 26年 72.7%」と記載しているが、これは誤ラベルであると判断した（ユーザー確認済み）。根拠：
- この2つの数値は、既存の `src/components/KokushiReport.astro` に掲載されている**本学自身の**合格率（前2回＝第38・39回平均 83.9%、第40回 72.7%）と完全一致する。
- pptxに埋め込まれたグラフ（`ppt/charts/chart1.xml`、ラベルなし）は22〜26年で 92.9%→87.2%→80.4%→80.1%→79.3% の別系列を持ち、これは`KokushiReport.astro`記載の「全国平均（第40回）79.4%」とほぼ一致する（グラフ側が実際の全国平均5年推移）。
- 2系列の25年時点の値（テキスト83.9% vs グラフ80.1%）が食い違うことからも、同一系列の読み違いではなく、テキスト側のラベル誤りと判断できる。

**採用する数値（`KokushiReport.astro`と完全一致させる）:**
- 本学 合格率（第38・39回平均）: 83.9%
- 本学 合格率（第40回）: 72.7%
- 全国平均（第40回）: 79.4%
- 補足文脈として「全国平均も5年間で90%台から70%台後半まで低下＝試験全体が難化傾向」を使ってよい（グラフ92.9%→79.3%が根拠）。

## NationalExamSupport.astro の構成

現在は緑背景の`.support`セクション1つ（6項目グリッド）のみ。これを2パートに再構成する。

### Part A（新規。`summary`モードでは非表示、`/support`のフルページのみ）

既存の `KokushiReport.astro` が使っている白背景系CSSクラス（`.kr-section` `.kr-section__label` `.kr-section__title` `.kr-stats-row` `.kr-stat` `.kr-body` `.kr-list` `.kr-cause-grid` `.kr-cause-card` `.kr-link-btn` など）をそのまま流用する。新規CSSは追加しない方針。`.support`セクションの前に配置する。

**1. 合格率セクション**
- ラベル: `Section 01`
- タイトル: 「管理栄養士国家試験の合格率」
- 導入文: 「管理栄養士になるには、管理栄養士国家試験に合格する必要があります。試験は年々難化傾向にあり、4年生になってから対策を始めても間に合いません。」
- `kr-stats-row`（3項目）:
  - 83.9% ／ 本学 合格率（第38・39回平均）
  - 72.7% ／ 本学 合格率（第40回）※ハイライト
  - 79.4% ／ 全国平均（第40回）
- 補足文: 「全国平均も5年間で90%台から70%台後半まで低下しており、試験全体が難化傾向にあります。夢を実現するために、入学した今から勉強習慣をつけておきましょう。」
- リンクボタン（`kr-link-btn`）: 「国試レポートを読む」→ `/kokushi-report`

**2. 試験内容セクション**
- ラベル: `Section 02`
- タイトル: 「管理栄養士国家試験の内容」
- 導入文: 「試験の内容は以下のように多岐に渡ります。そのため、1年生からの対策が必要となります。」
- `kr-list`（9科目、科目名＋対応する主な授業科目）:
  1. 社会・環境と健康（公衆衛生学、健康管理概論 など）
  2. 人体の構造と機能及び疾病の成り立ち（解剖生理学、病態生理学 など）
  3. 食べ物と健康（食品学I・Ⅱ、食品衛生学 など）
  4. 基礎栄養学
  5. 応用栄養学（応用栄養学I〜Ⅲ など）
  6. 栄養教育論（栄養教育論I・Ⅱ など）
  7. 臨床栄養学（臨床栄養学I〜Ⅳ など）
  8. 公衆栄養学（公衆栄養学I・Ⅱ など）
  9. 給食経営管理論（給食経営管理論I・Ⅱ など）
- 締め文（`kr-body--emphasis`）: 「管理栄養士国家試験は200問（200点満点）出題され、合格するためには120点以上の取得が必要です。」

**3. 学習サイクルセクション**
- ラベル: `Section 03`
- タイトル: 「大学の授業が、一番の国家試験対策です」
- 導入文: 「国家試験の内容は幅広いですが、その内容は大学の授業で1つずつ学びます。つまり、授業で学んだ内容を復習し、知識を積み重ねることが、国家試験対策の第一歩となります。」
- `kr-list`（4ステップ）: 授業で学ぶ → 復習する → 定期試験で確認する → 苦手分野を学び直す
- 具体例（`kr-body`）: 「例えば、1年生で習う食品学・食品衛生学は『食べ物と健康』に、解剖生理学は『人体の構造と機能及び疾病の成り立ち』に、基礎栄養学は『基礎栄養学』に、そのままつながっています。」
- 締め文: 「そのため本学では、授業で学んだ内容を振り返る習慣を身につけるこのサイクルを大切にしています。」

**4. 4年間ロードマップセクション**
- ラベル: `Section 04`
- タイトル: 「4年間の伴走ロードマップ」
- 導入文: 「入学前から4年次まで、段階的に国家試験対策を行います。大学の支援と学生自身の取り組みを組み合わせ、合格に必要な力を育てます。合格には学生自身の継続的な学習が欠かせません。十文字は、その努力を4年間支えます。」
- `kr-cause-grid`（4カード、`kr-cause-card__num`に時期を使う）:
  - 入学前 ／ 大学の支援：勉強方法のガイダンス／学生の取り組み：高校までの学習を振り返る
  - 1・2年次 ／ 大学の支援：授業による基礎力の定着、定期試験による到達度確認／学生の取り組み：授業の復習を習慣化する
  - 3年次 ／ 大学の支援：模試や外部講座の実施、苦手分野の確認／学生の取り組み：模試の復習、学修計画の実行
  - 4年次 ／ 大学の支援：模試や外部講座の実施、夏期講習や寺子屋の実施／学生の取り組み：苦手分野の克服、試験に備える

### Part B（既存の`.support`緑背景セクション。3項目に再編、`summary`/フル共通）

`ITEMS`配列を6項目→3項目に置き換える（`summary`時のスライスは不要になり、`ITEMS`をそのまま使う）。

```
01 対策開始がとにかく早い
   本学では、常に国家試験を意識した授業を実施し、2年生から模擬試験も始まります。入学前には入学者対象イベント「十文字デビューDay」を実施し、勉強法についてもしっかりアドバイス。入学前から国家試験対策を始めることができます。

02 集中講座で苦手分野を克服
   4年生の夏休みに夏期講習を実施。午前中から夕方まで9日間、集中的に勉強することで苦手分野を克服し、合格に近づきます。

03 十文字オリジナル問題集
   各分野の教員が協力し、オリジナル問題集を作成。独自の問題集を利用することで十文字に特化したきめ細やかな対策が可能です。必要に応じて、各教員が質問対応や独自の対策講座も実施します。
```
