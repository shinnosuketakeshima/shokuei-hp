# 補完サイト トップページ改善提案
**対象**: https://shokuei-hp.web.app（十文字学園女子大学 食物栄養学科 補完サイト）
**作成方針**: 本文改稿よりも「見せ方・導線・情報設計・検索」を最優先。スポーツ栄養ページ・既存記事資産は大きく変更しない。

## 1. 現状課題の整理

### 1-1. SEO上の課題
| 課題 | 詳細 |
|---|---|
| トップのタイトル・ディスクリプションが「学科紹介」止まり | `PAGE_META['/']` のtitleは「管理栄養士・栄養士を育成」など公式サイトと被る訴求軸。**補完サイトならではの検索意図**（「十文字 食物栄養 リアル」「十文字 食物栄養 評判」「十文字 食物栄養 学生」等）を拾う語彙が薄い |
| 公式サイトとのキーワード競合 | 「食物栄養学科」「管理栄養士」「十文字学園女子大学」など主要語で公式と同じ土俵に立つと、Googleは公式を優先しがち。補完サイトは**ロングテール・サジェスト語・検索者の "気持ち" に寄り添う語**で差別化すべき |
| 内部リンクが「面」になっていない | トップ→各下層への導線はあるが、下層記事同士・記事→学科情報ページへの**回遊リンク**が薄い。記事ページ単体で読み終わり、離脱しやすい構造 |
| h1/h2の設計が「公式紹介文」型 | 多くの下層ページタイトルが「○○研究室（専門分野） \| 大学名 学科名」という**カタログ型**。検索者の質問形（「管理栄養士になるには」「十文字 食物栄養 きつい」等）に答える見出しが少ない |
| クリック率を左右する差別化要素が薄い | meta descriptionが「紹介文」中心で、「公式には載っていない」「学生のリアルな声」という**補完サイトだけの価値**が一覧（検索結果）の時点で伝わりにくい |

### 1-2. GEO上の課題
| 課題 | 詳細 |
|---|---|
| 定義文（〜とは）が散在・不足 | 生成AIが引用しやすい「食物栄養学科とは」「管理栄養士とは」「ダブルライセンスとは」のような**1〜2文で完結する定義ブロック**がトップ・各記事に明示的に置かれていない（FAQ JSON-LDはあるが、本文中の定義文は薄い） |
| 情報の粒度がページ間でバラバラ | 数値（就職率99.2%、定員78名、模試8回など）はStatsBar・FAQ・各ページに分散しているが、**書き方の粒度・年度表記が統一されていない**箇所がある（生成AIは粒度が揃っている情報を優先的に統合する） |
| 1段落が長め・修飾が多い | Hero・各セクションのリード文は「情緒的な長文コピー」型。生成AIの要約や引用には**「結論→具体・短文」**の構造が再利用されやすいが、現状は「情景描写→結論」の順が多い |
| FAQの所在がトップから遠い | `/faq` は独立ページ＋トップに `summary` 表示があるが、**「進路指導教員向け」「保護者向け」**で質問を分けたセクションがなく、生成AIが「進路指導教員に説明する場合」のような문脈別回答を作りにくい |
| 「公式サイトとの関係」が明文化されていない | 生成AIが「このサイトは何か」を判断する材料（補完サイトである旨の定義文）がページ内テキストに存在しない（JSON-LDの`description`にはあるが、本文に露出していない） |

### 1-3. 高校生に届きにくい点
- ファーストビューのコピー「『食』を、科学する。社会を、動かす。」は**情緒的でブランド感は出るが、「自分にとって何の場所か」が一瞬で伝わらない**。高校生は3秒で「自分ごと化できるか」を判断する
- CTAが「学生たちのリアルを見る」「12の研究室ストーリー」「公式サイトでカリキュラムを見る」の3本だが、**「保護者」「進路指導教員」の動線がトップ最上部に存在しない**
- スマホ前提のユーザーが大半なのに、ファーストビューで「次に何をすればいいか」（資料請求？オープンキャンパス？記事を読む？）の**優先順位が示されていない**
- 「管理栄養士になりたい」段階の高校生だけでなく、「食に興味はあるが管理栄養士はまだ決めていない」段階の高校生も多い。**間口を広げる検索語・見出し**（「栄養 大学 やりたいこと探し」等）への対応が手薄

## 2. サイト全体の方針

### 2-1. この補完サイトの役割定義
> **「公式サイトが伝えにくい "中の空気・人の言葉・リアルな1日" を、検索エンジンと生成AIの両方から見つけてもらい、最終的に公式サイト（出願・カリキュラム・入試情報）へ橋渡しするメディア」**

公式サイトが「制度・カリキュラム・入試要項という"骨格"」を担うなら、補完サイトは「学生・教員の"声"と"現場の温度"という"血肉"」を担う。両者が揃って初めて受験生の意思決定材料になる、という構図を明確にする。

### 2-2. 公式サイトとの棲み分け
| | 公式サイト | 補完サイト（本サイト） |
|---|---|---|
| 役割 | 制度・入試・カリキュラムの「正」の情報源 | 学生・教員のリアル、雰囲気、補足説明の「副」の情報源 |
| トーン | フォーマル・網羅的 | 親しみやすい・物語的・編集的 |
| コンテンツ | 学科概要、入試要項、施設一覧 | 研究室ストーリー、学生コラム、教員コラム、イベントレポート、国試結果分析 |
| 検索意図 | 「十文字 食物栄養 入試」「十文字 食物栄養 カリキュラム」 | 「十文字 食物栄養 雰囲気」「十文字 食物栄養 リアル」「管理栄養士 大学生活」 |
| 最終導線 | 出願・資料請求 | **公式サイトへの送客**（このサイト自体がコンバージョン地点にならない） |

→ トップページのあらゆる導線の「最終到達点」は、**①公式サイトの該当ページ、②本サイト内の深掘り記事、③オープンキャンパス・資料請求への外部リンク**のいずれかに収束させる設計にする。

### 2-3. 変更してよい部分／変えない部分
| 変えてよい（最優先） | 変えない（厳守） |
|---|---|
| トップページのファーストビュー文言・導線設計 | スポーツ栄養ページ本文（`SportNutritionPage.jsx`） |
| トップのセクション構成・並び順・見せ方 | 他学科・関係者と協議済みのページ（`/koudai-project`, `/lab-kamiyama-report` など連携系） |
| 各記事への「見出し・リード文・サムネ訴求」のメタ的な見せ方（記事一覧・カード文言） | 既存の良質記事の本文（学生コラム・教員コラム・研究室レポート） |
| meta title / description / 構造化データの調整 | News.jsx の Firestore 連携ロジック自体 |
| 内部リンクの追加・整理 | 記事の内部の事実関係・数値（年度実績など） |
| FAQの構成・配置 | デザインシステム（`index.css` のトークン）の大幅刷新 |

### 2-4. 情報設計の基本方針
1. **「誰のための情報か」を最初の3秒で示す** — 高校生／保護者／進路指導教員の3導線をファーストビュー直下に明示
2. **1ページ1テーマ・1問1答** — 記事・セクションは「何の質問に答えるページか」を1つに絞る（GEO観点）
3. **公式サイトへの送客を「ゴール」として設計** — 補完サイト内で完結させようとしない。要所要所で「詳しくは公式サイトで」を自然に挿入
4. **既存資産の「読ませ方」を変える、書き方は変えない** — カード文言・導線順・カテゴリ分類の編集力で資産価値を底上げする

## 3. トップページの改善案

### 3-1. ファーストビュー見出し案（3案）

| 案 | 見出し | 狙い |
|---|---|---|
| **A：自分ごと化重視** | **「管理栄養士をめざす毎日って、実際どんな感じ？」**<br>サブ：十文字学園女子大学 食物栄養学科のリアルを、学生と教員の言葉で。 | 高校生の検索行動（「〜って実際どう？」型）にそのまま応える疑問形。クリック後の期待値を裏切らない |
| **B：現行コピー継承＋説明補強** | **「『食』を、科学する。社会を、動かす。」**<br>サブ：十文文字学園女子大学 食物栄養学科の「リアルな4年間」を伝える、学科公認の補完メディア。 | ブランドコピーの世界観を残しつつ、直後の1文で「補完メディアである」ことと「何が見られるか」を補う折衷案 |
| **C：検索語直結型** | **「食物栄養学科のリアルを、学生・教員のことばで。」** | 「食物栄養学科」「リアル」という検索・サジェスト頻出語を見出しに自然配置。SEO・GEO両面で引用されやすい簡潔な定義文型 |

**推奨：A（または A→Bのハイブリッド）**。理由：高校生は「公式の紹介文」にはすでに飽きている。検索クエリに最も近い「問い」の形にすることで、SEOの検索意図一致・GEOの引用適性（Q&A形式）の両方を満たせる。

### 3-2. 短い説明文案（リード文・3案）

| 案 | 本文 |
|---|---|
| **①定義文型（GEO最適化）** | 「ここは、十文字学園女子大学 食物栄養学科の "公式サイトでは見えにくい部分" を伝える補完サイトです。研究室の素顔、学生の本音、教員の言葉を通じて、入学後の毎日をリアルに知ることができます。」 |
| **②ベネフィット直結型（高校生向け）** | 「管理栄養士になるために、この学科で何を学び、どんな4年間を過ごすのか。在学生・卒業生・教員のリアルな声から、"自分がここにいる姿" を想像してみてください。」 |
| **③信頼・実績接続型（保護者・教員向け）** | 「就職率99.2％、管理栄養士国家試験への手厚いサポート体制——数字の裏にある「学びの現場」を、研究室・実習・学生コラムを通じてお伝えします。詳しい制度・入試情報は公式サイトをご覧ください。」 |

**推奨**：①をファーストビュー直下の固定リードに採用し、②③はそれぞれ「高校生向け導線」「保護者・教員向け導線」の見出し直下に再配置する（後述3-4）。① は「補完サイトとは何か」を最初に明確化することで、生成AIの引用元としても機能する定義文になる。

### 3-3. 主要導線の並べ方（トップ全体構成・改訂案）

現行：`Hero → FeatureSpotlight → CategoryBanners → News → StatsBar → Features → Labs → Qualifications → Support → SNS → Career → Voices → CampusLife → FAQ`

**改訂案**（変更点に★）：

```
1. Hero（★コピー差し替え／導線3分岐に再設計）
2. ★「あなたはどなた？」3導線セレクター（新設・軽量セクション）
     - 高校生の方へ → #voices / #labs
     - 保護者の方へ → #support / #career（実績データ）
     - 進路指導の先生へ → 公式サイトの該当資料 + FAQ
3. FeatureSpotlight（現状維持。ただしカード文言は3-5で調整）
4. CategoryBanners（現状維持）
5. StatsBar（★Newsより前に繰り上げ：信頼の数字を早めに提示しGEO的にも引用されやすい位置に）
6. News（★「最新の学びの現場から」に文脈づけ。記事カードに一言の「読みどころ」を付与）
7. Features summary
8. Labs
9. Qualifications summary
10. NationalExamSupport summary
11. SNSSection

```

**狙い**：
- 「3導線セレクター」を冒頭近くに置くことで、3者それぞれが「自分の知りたい情報まで最短2クリック」で到達できる

- 最後に「公式サイトへ」のCTAブロックを置くことで、補完サイトとしての着地点を明確化する

### 3-7. 公式サイトへの送り方

## 4. SEO設計案

### 4-1. 推奨ページタイトル案（トップページ）

| 現行 | 改善案 |
|---|---|
| `食物栄養学科 \| 十文字学園女子大学 - 管理栄養士・栄養士を育成` | `食物栄養学科のリアルを学生・教員の声で｜十文字学園女子大学 補完サイト` |

理由：「管理栄養士・栄養士を育成」は公式サイトと完全に競合する語。代わりに**「リアル」「学生・教員の声」「補完サイト」**という、このサイトにしかない独自ポジションを前面に出すことで、検索結果上での差別化と適切な検索意図のユーザーを呼び込む。

### 4-2. meta description案（トップページ）
> 「十文字学園女子大学 食物栄養学科の "もうひとつの顔" を伝える補完サイト。研究室の素顔、学生コラム、教員のことば、国家試験サポートのリアルな様子を発信。公式サイトと合わせて読むことで、入学後の毎日がより具体的に見えてきます。」

- 「補完サイト」という立ち位置を明記（公式との誤認防止＋GEOでの正確な文脈付与）
- 「研究室」「学生コラム」「教員」「国家試験」など主要内部コンテンツへの期待値を提示
- 「公式サイトと合わせて読む」という一文で、棲み分けを検索結果の時点から伝える

### 4-3. h1案（トップページ）
- `「管理栄養士をめざす毎日って、実際どんな感じ？」`（3-1案A準拠）
- 視覚的なブランドコピー（「食を、科学する」）は h1 ではなく装飾的なキャッチコピーとしてh1の前後に配置し、**SEO上のh1は検索意図に最も近い疑問形・説明形**にする

### 4-4. h2案の設計方針
- 各セクションの見出しは**「○○とは」「○○な理由」「○○の実態」**のような検索意図直結型の語尾を意識する
- 例：
  - 現行「あなたの『好き』から、学びを選ぶ」→ そのまま維持可（検索意図には強くないが、サイト内回遊導線としては機能している）
  - 新設セクション見出し例：「食物栄養学科で学べることは？」「管理栄養士になるための4年間のリアル」「先輩たちの『十文字を選んだ理由』」
- 1セクション1見出し1テーマを徹底し、見出し配下の本文は**結論→具体例→次の導線**の順で統一する

### 4-5. 内部リンク戦略

## 5. GEO設計案

### 5-1. 定義文の置き方
- 各主要セクション・各記事の**冒頭1〜2文**に「これは何のページ／何の話か」を明示する定義文を置く
- 例（トップページ冒頭）：
  > 「このサイトは、十文字学園女子大学 食物栄養学科の補完サイトです。公式サイトでは伝えきれない、学生・教員のリアルな声や研究室の日常を発信しています。」
- 例（研究室ページ冒頭の型）：
  > 「○○研究室は、△△を専門とする研究室です。□□というテーマに取り組んでおり、××という学びを得られます。」
- **「である」「です」で終わる短文・定義文型**を意識し、生成AIがそのまま引用・要約に転用しやすい構造にする

### 5-2. 箇条書きの作り方
- 1項目＝1情報・1事実に限定する（複数の情報を1項目に詰め込まない）
- 数値を含む項目は**「数値＋単位＋年度（出典時期）」**を必ずセットで記載する
  - 良い例：「就職率99.2%（2025年3月卒業生実績）」
  - 避けたい例：「高い就職率を誇ります」
- 箇条書きの冒頭語を統一する（体言止め／「〜できる」型など、リスト内で文体を揃える）
- FAQセクションでは「Q：〜とは？／A：〜です。」の対構造を崩さない（既存の構造化データ運用と一致させる）

### 5-3. AI検索で引用されやすい文の特徴（チェックリスト）
- [ ] 1文が60〜80文字程度で完結している（長い修飾節を避ける）
- [ ] 「〜と思われます」「〜かもしれません」など曖昧表現を避け、事実は断定形で書く
- [ ] 1段落＝1トピックで、段落の最初の1文に結論を置く（**結論ファースト**）
- [ ] 固有名詞（学科名・大学名・資格名・実習名）を省略代名詞（「ここ」「この学科」等）に頼らず、繰り返し明記する
- [ ] 「誰が」「何を」「いつ」「どのくらい」が1文または隣接する2文以内に揃っている

### 5-4. 1段落の理想的な長さ
- **本文：3〜4文・150〜200字程度**を目安に区切る（生成AIの抽出単位に合わせる）
- 長い情緒的なリード文（現行Heroのような表現）はビジュアル要素として残しつつ、**その直後に短い説明的補足文（定義文型）を必ず併設**する

### 5-5. FAQの作り方
- 既存の `customJsonLd`（FAQPage構造化データ）の運用は良好。これを土台に：
  - **「進路指導教員向け」「保護者向け」**で質問をグルーピングし、見出しレベルで明示する（例：「進路指導の先生からよくいただく質問」）
  - 質問文は検索クエリに近い口語表現で統一する（「〜は何ですか？」「〜できますか？」）
  - 回答は**「結論→具体的な数値・制度名→補足」**の順で統一し、最初の1文だけでも独立して引用可能な形にする

### 5-6. 生成AIに拾われやすい構造（まとめ）
- ページ冒頭＝定義文 → 中盤＝具体例・数値 → 末尾＝関連リンク・FAQという**「型」をサイト全体で統一**する
- 見出し（h2/h3）は疑問形または体言止めで統一し、**文章の途中で文体（です・ます／である）が混在しない**ようにする
- 「公式サイトの情報を補完するための独自情報である」旨を、各記事の冒頭または末尾で簡潔に繰り返す（生成AIが情報源の性質を正しく認識する助けになる）

### 5-7. 進路指導教員・保護者に届きにくい点（対策含む）
- 現状、`StatsBar` や `customJsonLd` のFAQには実績数値が整っているが、**「進路指導の先生がそのまま生徒に説明できる要約」**がまとまったページがない
- → `/features` または `/faq` に「進路指導の先生・保護者の方へ：学科の特色を3分でまとめると」という**要約セクション**を新設し、数値・制度・進路実績を1画面で俯瞰できる構成にする（既存ページの追記レベルで対応可能）

### 5-8. 公式サイトとの役割分担上の課題
- 現状、サイト内テキストに「補完サイトである」という明言がほぼない（構造化データの`description`にのみ存在）
- → 各ページのフッター直前、または記事末尾に**「※本サイトは十文字学園女子大学 食物栄養学科の補完サイトです。入試・出願に関する正式な情報は公式サイトをご確認ください」**という定型注記を設置し、検索結果・生成AI双方に「正しい立ち位置」を伝える
