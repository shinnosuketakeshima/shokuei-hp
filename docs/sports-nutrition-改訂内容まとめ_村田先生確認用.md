# スポーツ栄養特設ページ（/sports-nutrition）改訂内容まとめ

村田先生にご確認いただきたい主要な変更点を、修正前後で比較できる形でまとめました。
ページ全体の構成・文章は `src/components/SportNutritionPage.jsx` をご覧ください。

---

## 1. ページの位置づけの変更

- **修正前**：「食物栄養学科のコンテンツ」という枠組みでの掲載
- **修正後**：「食物栄養学科 × 健康栄養学科 共通スポーツ栄養特設ページ」として、両学科の志望者・在学生のどちらにも自分のキャリアと直結すると感じられる構成に変更

## 2. 個人名の掲載基準の統一

- **修正前**：本文（誤解を解くセクション、ルート紹介など）の中に教員名が直接登場
- **修正後**：
  - 本文中の個人名はすべて削除し、「公認スポーツ栄養士」「日本スポーツ栄養学会の理事クラス」など、客観的な専門性・実績の記述に統一
  - ページ最下部に「**講義・教員紹介**」の専用セクションを新設し、講義名と教員名をセットで掲載（カード型＋シンプルなリスト形式）

---

## 3. 村田先生の紹介内容（最も大きな変更点）

### 修正前

> 「時間栄養学」をアスリート現場に導入し、持続血糖測定器（CGM）を用いた高強度運動時の低血糖防止策など最先端の栄養アセスメントを研究。本学大学院（食物栄養学専攻修士課程）の研究指導も担当しており、学部から大学院まで一貫した指導が受けられます。

- 専門分野タグ：健康スポーツ科学／スポーツ栄養学／環境生理学／**時間栄養学**
- バッジ：日本スポーツ栄養学会 理事／大学院 研究指導担当
- 担当科目の表記：なし（誤解セクション内に教授名のみ言及）

### 修正後

> 競技者を対象とした食事調査を中心に、栄養アセスメント研究の第一人者として国内外の学会で多数の発表を重ねる。本学大学院（食物栄養学専攻修士課程）の研究指導も担当しており、学部で学んだ学生がさらに専門性を高めるために教授ゼミへ進学する道も開かれている。実際に、ゼミ出身の大学院生が競技者の食事調査に関する研究で、昨年の日本スポーツ栄養学会大会において演題賞を受賞——「入学・学部・大学院・キャリアアップ」という一貫した学びの好例を、自らのゼミから生み出している。

- 専門分野タグ：健康スポーツ科学／スポーツ栄養学／**栄養アセスメント／競技者の食事調査**（「時間栄養学」の表記は外しました）
- バッジ：日本スポーツ栄養学会 理事／大学院 研究指導担当（変更なし）
- **新規**：担当科目を明記 →「担当科目：栄養指導論／応用栄養学」をお名前と並べて表示

### 変更の意図

- 「時間栄養学・CGM」という先端研究の切り口から、「**競技者の食事調査・栄養アセスメント研究の第一人者**」という訴求の軸に変更（ご相談いただいた方針に沿ったものです）
- 大学院ゼミ卒業生の演題賞受賞エピソードを加え、「入学 → 学部 → 大学院 → キャリアアップ」というロールモデルのストーリーを構築
- 必修科目（栄養指導論・応用栄養学）を担当している事実を明記し、「トッププロが必修科目を教えている」価値をアピール

## 4. 徳野先生の紹介内容

### 修正前
> 現役の「公認スポーツ栄養士」として実際の栄養サポート活動を展開する実践家。講義・実習を通じて、学生への公認スポーツ栄養士としてのキャリアパス提示も積極的に行っています。

### 修正後
> 必修科目「公衆栄養学」とその演習・実習を担当。現役の公認スポーツ栄養士として、実際にスポーツ選手への栄養サポート活動を重ねてきた実践家でもある。講義・実習を通じて、現場経験に裏打ちされた知見を伝えるとともに、学生への公認スポーツ栄養士としてのキャリアパス提示にも力を入れている。

- **新規**：担当科目を明記 →「担当科目：公衆栄養学（演習・実習）」

## 6. その他の主な内容変更

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 「スポーツ栄養（講義・座学）」の訴求 | 教員名・学科に紐づいた紹介中心 | 「アスリートとノンアスリートが共に学ぶ環境」「健康栄養学科との同時開講（共通化予定）」を前面に |
| 「健康栄養ゼミ」の表記 | 「健康栄養ゼミに参加」 | 「各学科の専門ゼミに参加」に修正（共通化に合わせた正確な表現） |
| 学校教育×スポーツ栄養 | キャリア例の一つとして言及する程度 | 新規セクション「本学独自の強み：学校現場こそ、スポーツ栄養の最前線」を新設し、保健体育教諭・栄養教諭としての道を強く訴求 |
| 社会人ルート | 「働きながら資格取得を目指す」という一般的な説明 | 「在学中からスポーツ現場でのサポート経験を積めることが、他校にはないアドバンテージ」という現実的なメリットを明記したルートカードを新設 |
| 学生アスリートのキャリアマップ | 卒業後に管理栄養士として活躍、で完結 | 「管理栄養士として活躍 → 競技経験を生かした栄養管理業務 → サポート経験の蓄積 → 公認スポーツ栄養士資格の取得」という確実なステップアップルートを追加 |
| スポーツ栄養の普遍的価値 | 言及なし | 新規セクション「スポーツ栄養の知識は、アスリートだけのものではない」を新設し、幼児期〜高齢期まで応用可能な汎用性の高い知識であることを総括として明記 |

## 7. ページ構成（セクション順）

1. ヘッダー（タイトル・リード文）
2. よくある誤解（個人名を排除し、客観的な事実ベースの記述に統一）
3. **〔新設〕** 本学独自の強み：学校現場こそ、スポーツ栄養の最前線
4. 十文字でのスポーツ栄養との関わり方（3カード）
5. スポーツ関連科目一覧
6. スポーツと栄養をつなぐ、4つのルート（社会人ルートを新設し3→4に拡充）
7. スポーツ栄養の知識で広がるキャリア
8. **〔新設〕** スポーツ栄養の知識は、アスリートだけのものではない（総括）
9. **〔新設〕** 講義・教員紹介（教員スポットライト＋シンプルな講義担当者リスト）
10. CTA（2学科への導線）
